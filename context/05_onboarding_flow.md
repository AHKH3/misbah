# 05 — Onboarding Flow

## خطوات التسجيل (6 خطوات)

### Step 1: البيانات الشخصية
| الحقل | النوع | مطلوب |
|-------|-------|-------|
| الاسم بالعربي | Text | ✅ |
| الاسم بالإنجليزي | Text | ✅ |
| اللقب | Radio (شيخ/أستاذ/معلم) | ✅ |
| الجنس | Radio (ذكر/أنثى) | ✅ |
| تاريخ الميلاد | Date | ✅ (≥ 18 سنة) |
| البلد | Select (50+ بلد) | ✅ |

### Step 2: التخصص واللغات
**المواد** (multi-select، مطلوب ≥ 1):
- قرآن → تخصصات فرعية: تحفيظ، تلاوة، إجازة، مراجعة
- عربية → تخصصات فرعية: عربي كلغة ثانية، قراءة، نحو، محادثة
  - مناهج: العربية بين يديك، مدينة، مخصص
  - قراءة: نور البيان، القاعدة النورانية
- دراسات إسلامية → فقه، عقيدة، تفسير، حديث، سيرة

**اللغات** (multi-add، مطلوب ≥ 1):
- اللغة + المستوى: مبتدئ / متوسط / متقدم / لغة أم
- 20 لغة متاحة

### Step 3: التعليم والخبرة
**التعليم** (Timeline، مطلوب ≥ 1):
- النوع: ديني، أكاديمي، إجازة، دورة، أخرى
- الدرجة: ثانوي، دبلوم، بكالوريوس، ماجستير، دكتوراه، أخرى
- المؤسسة، التخصص، سنة البدء/الانتهاء
- ملاحظات (اختياري)

**الخبرة** (Timeline، مطلوب ≥ 1):
- نوع المؤسسة: أكاديمية، مركز، مسجد، خاص، أونلاين، أخرى
- الدور، شهر/سنة البدء والانتهاء (مع خيار "مستمر")
- الوصف (اختياري)

### Step 4: الجمهور والتسعير والبايو
- عمر الطلاب: حد أدنى/أقصى (اختياري)
- جنس الطلاب: ذكور / إناث / الاثنين
- السعر: المبلغ + العملة (EGP/USD) (اختياري)
- **البايو بالعربي** (مطلوب - مهم للـ SEO)
- **البايو بالإنجليزي** (مطلوب - مهم للـ SEO)

### Step 5: الفيديو التعليمي
- رابط يوتيوب (مطلوب)
- يقبل: youtube.com/watch, youtu.be, youtube.com/embed, youtube.com/shorts
- الحد الأدنى: درس كامل ≥ 20 دقيقة أو تلاوة صفحة كاملة بالتجويد

### Step 6: التواصل والقانوني
**طرق التواصل** (مطلوب ≥ 1):
- واتساب (رقم)
- تليجرام (username)
- إيميل (للتواصل مع الطلاب)
- موقع (اختياري)

**إيميل مصباح** (مطلوب - للتواصل مع مصباح):
- واضح أنه "للتواصل معنا وإبلاغك بنتيجة المراجعة"
- ليس لإنشاء حساب

**صيغة التدريس**: أونلاين (ثابت - عرض فقط)

**الإقرارات القانونية** (4 checkboxes، كلها مطلوبة):
1. أنا أدرّس بنفسي شخصياً
2. لن أحوّل الطلاب لمنصات أخرى
3. أتحمل عواقب المخالفة
4. إقرار قانوني عام

## مسار المعلم الكامل

```
تسجيل (6 خطوات) → تأكيد إيميل (ضمني) → under_review
→ بوت تليجرام يبلّغ الأدمن → الأدمن يراجع (≤ 24 ساعة)
→ قبول: إيميل "ادفع عشان يكتمل حسابك" + رابط صفحة الدفع
   [مؤسس: إيميل "أنشئ كلمة مرورك" مباشرة - بدون دفع]
→ المعلم يدفع → يرفع صورة → بوت يبلّغ الأدمن
→ الأدمن يتأكد (≤ 24 ساعة) → حذف صورة الدفع
→ إيميل "أنشئ كلمة مرورك" → المعلم ينشئ حسابه → published
```

---

## نظام الحظر

- **المرفوض**: حظر افتراضي 30 يوم
- بعد انتهاء الحظر: إعادة التسجيل مع **رسوم مراجعة**
- **الأدمن يختار مدة الحظر**: 30 يوم / 90 يوم / دائم (للمحتالين)

---

## كشف التكرار (نظام نسبة التطابق)

| الحقل | الوزن |
|-------|-------|
| الاسم (عربي أو إنجليزي) | 30% |
| رقم الواتساب | 25% |
| رابط اليوتيوب | 20% |
| البلد + المواد | 15% |
| رقم التليجرام | 10% |

- **≥ 60%**: تنبيه عادي للأدمن
- **≥ 85%**: تنبيه أحمر (احتمال كبير نفس الشخص)

---

## الإيميلات (Resend)

**للمعلم** (2 إيميلات فقط):
1. بعد القبول → "تم قبولك! ادفع من هنا [رابط]"
2. بعد تأكيد الدفع → "أنشئ كلمة مرورك [رابط]"

**للمؤسسين** (إيميل واحد): "تم قبولك! أنشئ كلمة مرورك [رابط]"

**لا يوجد** إيميل "استلمنا طلبك" (الرسالة تظهر في الموقع نفسه)

---

## إشعارات الأدمن (Telegram Bot)

- معلم جديد سجّل → رسالة تليجرام (اسم + مواد + رابط مراجعة)
- معلم رفع صورة دفع → رسالة تليجرام
- تنبيه تكرار → رسالة تليجرام بنسبة التطابق

---

## التحقق (Validation)

| الحقل | القاعدة |
|-------|---------|
| الاسم | 2-50 حرف |
| إيميل مصباح | صيغة صحيحة + فريد |
| تاريخ الميلاد | ≥ 18 سنة |
| واتساب | 10-15 رقم |
| رابط يوتيوب | youtube.com أو youtu.be |
| المواد | واحدة على الأقل |
| التعليم | واحدة على الأقل |
| الخبرة | واحدة على الأقل |
| اللغات | واحدة على الأقل |
| طريقة تواصل | واحدة على الأقل |
| البايو (عربي + إنجليزي) | مطلوب (مهم للـ SEO) |
